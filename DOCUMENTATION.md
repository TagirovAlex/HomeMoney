# 🏠 HomeMoney: Руководство по развертыванию и эксплуатации (Deployment Guide)

## Введение
Данный документ описывает архитектуру, требования к окружению и шаги по запуску полнофункционального приложения для управления личными финансами. Приложение построено на принципах **Чистой Архитектуры**, что обеспечивает максимальную масштабируемость и тестируемость кода.

---

## 📂 Структура проекта (Codebase Structure)
```
HomeMoney/
├── models/database.py    # Определяет все ORM модели данных (User, Transaction, Budget и т.д.).
├── utils/database_session.py # Управляет подключением к SQLite и инициализацией БД.
├── data_access/repositories/  # Слой доступа к данным (Data Access Layer)
│   ├── user_repository.py    # Реализация репозитория пользователей.
│   ├── transaction_repository.py # Работа с транзакциями.
│   └── budget_repository.py  # Управление бюджетами.
├── services/financial_service.py # Бизнес-логика (Use Case Layer). Ядро системы, где реализованы все правила учета финансов.
├── app.py                 # Основной входной файл Flask API и роутинг.
├── handlers/command_handlers.py # Обработчики команд для Telegram Bot.
├── static/css/style.css   # Стилизация, включая Dark/Light Mode.
├── static/js/main.js      # Клиентская логика (JS) для фронтенда и управления темами.
└── templates/index.html  # Основной HTML-шаблон дашборда.
```

## 🛠️ Часть I: Требования к окружению (Prerequisites)
Для успешного развертывания требуется сервер с Python 3.10+ и **SQLite**.

**Установка зависимостей:**
В активированном виртуальном окружении (`venv`):
```bash
# Устанавливает все необходимые библиотеки
pip install flask sqlalchemy psycopg2-binary aiogram
```

## 🚀 Шаг 1: Инициализация БД и Админ-пользователь (Запускается скриптом)
Выполните следующие шаги для полной подготовки окружения.

**ВАЖНО:** Мы используем `install.sh` для автоматизации этого процесса, который гарантирует, что все таблицы созданы и создан тестовый администратор.

```bash
# Запуск мастер-скрипта (Убедитесь, что он доступен)
./install.sh 
```
*После этого шага в БД будут созданы все необходимые данные.*

## 🌐 Как запустить приложение:

**A. Web API:**
Запускайте через `app.py` и используйте Systemd для продакшена (см. секцию ниже).

**B. Telegram Bot:**
```bash
python telegram_bot.py
```
